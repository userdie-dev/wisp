# Закладки

## Хранилище

`@tauri-apps/plugin-store`, отдельный файл `bookmarks.json` (не смешивается с историей — разное назначение и время жизни данных).

```ts
interface Bookmark {
  id: string
  url: string
  title: string
  favicon: string | null
  folderId: string | null // null = корень
  createdAt: number
}

interface BookmarkFolder {
  id: string
  name: string
  parentId: string | null
}
```

Плоская схема папок (папка внутри папки — допустимо через `parentId`, без ограничения глубины), но UI в этапе 1 показывает только один уровень вложенности (см. ниже).

## Добавление закладки

- Кнопка-звёздочка (иконка `Star` из lucide) в тулбаре рядом с omnibox — переключает bookmarked-состояние текущей активной вкладки.
- Звёздочка закрашивается (`Star` → `fill="currentColor"`), когда `url` активной вкладки уже есть в закладках.
- Клик по не-закладке открывает маленький popover (Reka UI `Popover`) с полями: заголовок (по умолчанию title страницы), папка (select).

## UI внутренней страницы «Закладки»

`src/components/bookmarks/BookmarksView.vue`:

- Список закладок корня + список папок (раскрываются по клику, показывая закладки внутри).
- Клик по закладке → новая вкладка.
- Контекстное меню (Reka UI `DropdownMenu`) на каждой закладке: Открыть, Открыть в новой вкладке, Редактировать, Удалить.
- Кнопка «Новая папка».
- Drag-and-drop между папками — **не в этапе 1** (см. ниже).

## Панель закладок (bookmarks bar)

Не входит в этап 1 — только полноценная страница «Закладки». Полоска быстрого доступа под тулбаром — кандидат на этап 2.

## Не входит в первый этап

- Импорт/экспорт закладок (HTML-формат Netscape Bookmark File).
- Drag-and-drop сортировка и перенос между папками.
- Синхронизация между устройствами.
