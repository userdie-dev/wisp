# Настройка темы

## Хранилище

`@tauri-apps/plugin-store`, файл `settings.json`, ключ `"theme"`:

```ts
type Theme = 'system' | 'light' | 'dark'
```

## Реализация

- Tailwind CSS настроен с `darkMode: 'class'`.
- `stores/settings.ts` держит реактивный `theme`, и через `watchEffect`:
  - `'system'` → слушает `window.matchMedia('(prefers-color-scheme: dark)')`, применяет/снимает класс `dark` на `<html>` в зависимости от текущего значения, и переподписывается на изменения системной темы, пока выбран `'system'`.
  - `'light'` / `'dark'` → жёстко ставит/снимает класс `dark`, игнорируя системную тему.
- Дополнительно вызывается `getCurrentWindow().theme()`/тема окна не меняется программно (Tauri сам подхватывает системную тему для нативных элементов типа scrollbar на некоторых платформах) — здесь только CSS-класс, который красит наш собственный UI.

## UI

Внутренняя страница «Настройки» → секция «Тема» (`src/components/settings/ThemeSettings.vue`):

- Reka UI `RadioGroup` с тремя опциями: Системная / Светлая / Тёмная, с превью-иконками (`Monitor`, `Sun`, `Moon` из lucide).
- Изменение применяется мгновенно (без кнопки «Сохранить»).

## Дизайн-токены

Акцентный цвет, радиусы, тени и сами light/dark палитры — CSS-переменные в `src/assets/theme.css`, переопределяемые под `:root` и `.dark`. Компоненты используют только Tailwind-классы, завязанные на эти переменные (`bg-surface`, `text-fg`, и т.п. через `@theme` в Tailwind v4) — не хардкодят цвета, чтобы тема менялась в одном месте.

## Не входит в первый этап

- Пользовательские акцентные цвета/темы (кастомизация палитры).
- Раздельная тема для сайдбара/контента.
