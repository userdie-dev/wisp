# История посещений

## Хранилище

`@tauri-apps/plugin-store`, файл `history.json` в app data dir ОС. Никакого своего Rust-кода для чтения/записи — плагин официальный, вызывается прямо из Vue/Pinia.

```ts
interface HistoryEntry {
  id: string        // nanoid
  url: string
  title: string
  favicon: string | null
  visitedAt: number // epoch ms
}
```

Ключ в сторе: `"entries"` → `HistoryEntry[]`, ограничение по умолчанию — храним последние **10 000** записей (обрезаем старые при записи), чтобы файл не рос бесконечно.

## Запись

`stores/history.ts` подписан на событие `tab-updated` (эмиттится из Rust при `on_page_load`, см. [tabs.md](./tabs.md)). При изменении `url` вкладки (не при простом изменении title/favicon без смены url) — добавляет запись.

Намеренно **не** пишем историю для внутренних страниц (`app://history`, `app://settings` и т.п. — см. [architecture.md](../architecture.md)) и не пишем для приватных/incognito вкладок (зарезервировано на будущее, в этапе 1 инкогнито-вкладок нет).

## UI

Внутренняя страница «История» (`src/components/history/HistoryView.vue`):

- Список записей, сгруппированный по дню (Сегодня / Вчера / дата), сортировка от новых к старым.
- Поиск по истории (фильтр по `title`/`url` на клиенте, без индексации — объём небольшой).
- Клик по записи → открыть в новой вкладке (`tabsStore.createTab(entry.url)`).
- Кнопка «Очистить историю» (всю или за период: час/день/всё) — удаляет записи из стора и **не** трогает закладки (это независимые хранилища, см. [bookmarks.md](./bookmarks.md)).
- Удаление одной записи по hover-кнопке.

## Не входит в первый этап

- Полнотекстовый поиск по содержимому страниц.
- Синхронизация истории между устройствами.
