# Стартовая страница

Показывается вместо пустого места для только что открытой (`pending`) вкладки — вместо просто пустой вкладки без URL пользователь видит поисковую строку и быстрые ссылки, как в обычных браузерах.

## Когда показывается

Ровно тогда же, когда у активной вкладки `pending === true` (см. [tabs.md](./tabs.md), `Tab.pending`) — то есть для неё ещё не создан дочерний Rust-webview, потому что пользователь ещё никуда не перешёл. Рендерится самим chrome-webview (`src/components/starttab/StartPage.vue`), как и внутренние страницы История/Закладки/Настройки — область контента на это время становится непрозрачной (`ContentHost.vue`, `chromeRendered`), см. [architecture.md](../architecture.md).

Как только пользователь переходит куда-либо (submit в большой поисковой строке, в клик по быстрой ссылке, или ввод в омнибокс тулбара — все три вызывают один и тот же `tabsStore.navigate(id, url)`), `pending` становится `false`, создаётся реальный дочерний webview, и стартовая страница исчезает — контент вкладки показывается как обычно.

Тулбар (адресная строка сверху) остаётся видимым и на стартовой странице — как в Chrome/Edge, где верхний омнибокс показан всегда, а большая строка поиска на самой странице — это второй, более заметный вход для того же действия.

## Содержимое (этап 1)

- Заголовок «Новая вкладка».
- Большая поисковая строка по центру — тот же `resolveInput()` (см. [search-settings.md](./search-settings.md)), что и в обычном омнибоксе: URL открывается как есть, остальное — поиск через активную систему поиска.
- Быстрые ссылки — до 8 закладок из корня (без вложенности в папки, `folderId === null`), см. [bookmarks.md](./bookmarks.md). Клик открывает ссылку **в текущей (той же) вкладке**, а не в новой — так же, как обычно ведут себя стартовые страницы браузеров.

## Не входит в первый этап

- Самые посещаемые сайты по истории (top sites) — сейчас только закладки.
- Настраиваемые фоновые изображения/виджеты стартовой страницы.
- Отдельная настройка «что показывать при открытии новой вкладки» (стартовая страница жёстко зашита как поведение pending-вкладки).
