# Roadmap — идеи функционала

Список кандидатов на реализацию после этапа 1. Не приоритизирован жёстко — порядок
внутри блоков примерно по убыванию ценности. Отметка **[Rust]** — требует изменений
в `src-tauri/` (проверяется только в CI, локально Rust не ставим —
см. [setup-and-build.md](../setup-and-build.md)). Отметка **[front]** — только фронтенд.

По мере реализации пункт переносится в отдельный файл `docs/features/<feature>.md`
со спецификацией и удаляется/помечается здесь.

## Ядро браузинга

- **Восстановление сессии** [front] — ✅ спецификация:
  [session-restore.md](./session-restore.md). Осталось: вариант `homepage`
  с настраиваемым URL, восстановление после аварийного завершения.
- **Реальное состояние навигации** [Rust] — `canGoBack` / `canGoForward` из webview,
  чтобы кнопки назад/вперёд блокировались. Сейчас `tabs_back/forward` — слепой `eval`.
- **Индикатор загрузки и кнопка Stop** [Rust+front] — прогресс/спиннер во вкладке
  и тулбаре; событие начала загрузки (сейчас есть только `PageLoadEvent::Finished`).
- **Фавиконки** [front] — `Tab.favicon` сейчас всегда `null`. Фетчить фавикон
  по домену (`https://<host>/favicon.ico` или парсить `<link rel=icon>` через инъекцию).
- **Открытие ссылок в новой вкладке** [Rust] — обработка `target=_blank`,
  `Ctrl/Middle-click`, `window.open`. Сейчас новый webview для этого не создаётся.
- **Горячие клавиши** [front] — `Ctrl+T/W/L/R`, `Ctrl+Tab`, `Ctrl+Shift+Tab`,
  `Ctrl+1..9`, `Alt+←/→`, `Ctrl+F`.
- **Поиск по странице** (`Ctrl+F`) [Rust+front] — оверлей с подсветкой совпадений
  через инъекцию скрипта в webview.
- **Зум страницы** (`Ctrl +/-/0`) [Rust] — с сохранением уровня per-site.
- **Контекстное меню** (правый клик) [Rust] — открыть ссылку в новой вкладке,
  копировать адрес ссылки, назад/вперёд/обновить, сохранить изображение.
- **Менеджер загрузок** [Rust+front] — перехват download-событий WebView2/WebKit,
  панель со списком, выбор папки назначения.
- **Индикатор безопасности** [front] — замок `https`, показ реального источника
  в адресной строке, предупреждение о невалидном сертификате.

## Приватность и безопасность

- **Блокировка трекеров/рекламы** [Rust] — hosts-список + фильтрация запросов
  на уровне webview (scheme handler / navigation handler).
- **Очистка данных** [Rust+front] — куки, кэш, история за период; управление
  данными сайтов.
- **Приватные вкладки/окно** [Rust] — эфемерный профиль без записи в историю
  и с изоляцией хранилища.
- **Запросы разрешений** [Rust+front] — камера / микрофон / геолокация /
  уведомления с UI-промптом вместо тихого allow/deny.
- **HTTPS-only режим** [Rust], настраиваемый User-Agent [Rust].

## Продуктивность

- **Автодополнение omnibox** [front] — dropdown с подсказками из истории,
  закладок и поисковых подсказок движка; ключевые слова движков (`!g`, `!yt`).
- **Панель закладок** [front] — строка под тулбаром, папки, drag & drop.
- **Command palette** (`Ctrl+K`) [front] — быстрый переход по вкладкам / истории /
  действиям.
- **Reader mode** [front] — Readability.js, режим чистого чтения.
- **Группы вкладок / рабочие пространства** [front] — плюс поиск по вкладкам,
  закреплённые вкладки, перетаскивание вкладок в сайдбаре.
- **Split view** [Rust] — два webview рядом (multiwebview API уже есть).
- **Список для чтения / отложенное** [front].

## Кастомизация

- **Новая вкладка** [front] — обои, быстрые ссылки (top sites из истории),
  виджеты (погода / заметки).
- **Акцентный цвет / плотность интерфейса** [front], настраиваемые хоткеи [front].
- **Стартовое поведение** [front] — см. «Восстановление сессии».

## Платформа

- **Автообновление** [Rust+front] — ✅ спецификация: [auto-update.md](./auto-update.md).
- **PWA / режим приложения** [Rust] — установка сайта отдельным окном без тулбара.
- **Userscripts** [Rust+front] — мини-аналог Tampermonkey через инъекцию скриптов
  (полноценные расширения для системного webview недоступны).
- **Перевод страницы** [front], снимок страницы (в т.ч. full-page) [Rust].

## Рекомендуемый порядок

1. ~~Восстановление сессии~~ ✅ + состояние навигации + фавиконки + горячие клавиши.
2. Открытие ссылок в новых вкладках + контекстное меню + менеджер загрузок.
3. Автодополнение omnibox + command palette.
4. Reader mode + блокировщик + приватные вкладки.
